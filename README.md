# cps-tui

Declarative terminal UI framework for the CPS Nim runtime.

## Install

```sh
nimble install https://github.com/gabearro/cps-tui@#v1.0.0
```

```nim
import cps/tui
```

Dependencies are resolved automatically by Nimble: `cps-runtime`.

## Development

```sh
nimble install -d -y
nimble test
```

This repository was extracted from [gabearro/cps-runtime](https://github.com/gabearro/cps-runtime) with its relevant Git history preserved.
